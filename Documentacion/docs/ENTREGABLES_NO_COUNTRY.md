# Entregables Oficiales - Plataforma No Country (Hackathon ONE G10)

Este documento resume los 4 entregables requeridos en la plataforma de evaluación para el equipo del proyecto **NuevaMente**.

---

## Tarea 1: Documentación del Proyecto
- **Formato:** Markdown en la plataforma y archivo `README.md` en el repositorio.
- **Contenido Requerido:**
  - Descripción y propuesta de valor del proyecto.
  - Arquitectura RAG + LLMs + OCI Object Storage.
  - Guía de instalación y ejecución local.
  - Especificación de la API / Esquemas de entrada y salida JSON.
  - Equipo y roles.
- **Responsables:** Martin Morfe (PM) / Esteban Morales (Architect).

## Tarea 2: Video Demo del Proyecto
- **Formato:** Enlace de YouTube (Duración recomendada: 2:30 a 3:00 min).
- **Estructura del Guion:**
  1. **0:00 - 0:30:** Introducción, problema y solución NuevaMente.
  2. **0:30 - 1:15:** Carga de documento técnico y persistencia en OCI Object Storage (Always Free).
  3. **1:15 - 2:00:** Ejecución de RAG y adaptación según perfiles pedagógicos (ej. Principiante vs Arquitecto).
  4. **2:00 - 2:30:** Demostración del JSON de salida y resumen de impacto técnico.
- **Responsables:** Cristian Contreras & Diana Castaño (Frontend) / Harol Medina & Heiner Godoy (Full Stack).

## Tarea 3: Herramientas del Equipo
- **Formato:** Selección en la plataforma de No Country.
- **Tecnologías Clave:**
  - *IA / RAG:* LangChain, ChromaDB, Sentence Transformers, Google Gemini API, OpenAI API, Anthropic API, PyPDF, Pydantic.
  - *Frontend:* Streamlit, HTML5/CSS3.
  - *Cloud / Storage:* Oracle Cloud Infrastructure (OCI) Always Free, OCI Object Storage, OCI Python SDK (`oci`).
  - *DevOps & Colaboración:* Python 3.10+, Git, GitHub, Linux Ubuntu, Pytest.
- **Responsables:** Ivan Hernandez (DevOps) / Esteban Morales (Architect).
